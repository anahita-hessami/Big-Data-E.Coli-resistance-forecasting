# Archive

`Regional_Ecoli_BSI_AMR_Phase1.ipynb` is the first working version of this project — EU/EEA
persistence-vs-ML comparison and feature-group ablation, before the research-grade validation
layer (nested backtesting, multiplicity control, conformal intervals, partial pooling) existed.
It's kept for a transparent record of how the methodology evolved. `Regional_Ecoli_BSI_AMR_Complete_ML.ipynb`
in the parent folder supersedes it and is the notebook to run.

A pre-executed copy of Phase 1 (`Phase1_EXECUTED.ipynb`) is not kept here — at 13MB of embedded
plot output it duplicated content already visible in `notebooks/Regional_Ecoli_BSI_AMR_Complete_ML_EXECUTED.ipynb`.
Re-run `Regional_Ecoli_BSI_AMR_Phase1.ipynb` top to bottom if you want to see it with outputs.
